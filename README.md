Entry for the [make.fun competition "One Line to Your Younger Self"](https://make.fun/competitions/u-boothlord-one-line-to-your-younger-self-22e97f76): a program that writes the single line its writer would send back to their younger self, if one line were all they got.

## The line

> The money you're about to lend your best friend is already gone — lend it anyway, and buy the cheaper lesson.

## How it works

`main.ts` (Node 22) writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(falling back to `/output/entry.txt`), after checking it against the gate:
1–200 characters, not only whitespace, a single line.
